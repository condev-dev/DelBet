# 🎮 DelBet

**DelBet** – A high-fidelity, interactive front-end prototype simulating a modern **gaming & finance platform**.
Built with **HTML, CSS and Vanilla JavaScript**, crafted for **clarity, scalability and user engagement**.

> ⚡ **Portfolio-Level Project** – Showcasing Senior Front-End expertise in **interactive UI, responsive layouts and reusable component design**.

## ✨ Key Features

- 🏠 **Homepage** – Interactive games, live chat, the latest bets table and a winners showcase
- 💬 **Chat System** – Chat interface with message threads and a built-in emoji picker
- 👤 **Profile Page** – Update username, avatar and account details through smooth pop-ups
- 🛠 **Support Page** – Submit, view, edit and delete support tickets
- 💰 **Wallet Pages** – Deposit or withdraw USD / Bitcoin and manage crypto with QR codes (design only)
- ⚡ **Interactive Systems** – Pop-ups, chat, dynamic tables and micro-interactions across every page
- 📱 **Fully Responsive** – Tuned for desktop, tablet and mobile viewports
- 🧩 **Front-End Only** – The money flows are UI prototypes, no real transactions behind them

## 🗂 Pages

| Page | What it does |
| --- | --- |
| `index.html` | Homepage with interactive games, live chat, latest bets and winners |
| `profile.html` | Profile details, username and avatar updates |
| `support.html` | Support ticket list and submission form |
| `wallet.html` | Deposit / withdraw wallet screen |
| `wallet2.html` | Crypto buy / transfer screen with QR codes |

| `Forget Pass.html` | Password recovery screen |

## 🧩 Project Structure

| Path | Description |
| --- | --- |
| `assets/css/Main.css` | Design tokens, shared layout and components |
| `assets/css/*.css` | Per-page styles (profile, support, wallet, chat, login) |
| `assets/js/Main.js` | Pop-ups, chat, tables, sidebar and UI interactions |
| `assets/js/bootstrap` | Vendored Bootstrap grid, components and bundle |
| `assets/fontawesome-free-5.15.4-web` | Self-hosted Font Awesome 5 icons |
| `assets/font` | Self-hosted webfont |
| `assets/Image` | Logos, icons and README screenshots |

## ⚙️ How It Works

1. Sign in and land on the game lobby
2. Browse the interactive games, the latest bets table and the winners showcase
3. Open the live chat and send a message with the built-in emoji picker
4. Update your username, avatar and account details from the profile page
5. Create, edit or delete a ticket on the support page
6. Move to the wallet pages to deposit, withdraw or transfer crypto through QR codes (design only)
