# 🎮 DelBet

**DelBet** – A high-fidelity, interactive front-end prototype simulating a modern **gaming & finance platform**.  
Built with **HTML, CSS & JavaScript**, crafted for **clarity, scalability, and user engagement**.  

> ⚡ Designed as a **portfolio-level project** to showcase advanced UI/UX patterns, responsive layouts, and front-end craftsmanship.

## ✨ Core Highlights
> Designed, structured, and engineered with **Senior Front-End principles**:

- **🏠 Homepage:** Interactive games, dynamic chat, latest bets table, winners showcase  
- **👤 Profile Page:** Update username/avatar via pop-ups, smooth UX  
- **🛠 Support Page:** Submit, view, edit, or delete support tickets  
- **💰 Wallet Pages:** Deposit/withdraw USD or Bitcoin & manage crypto with QR codes (design only)  
- **⚡ Interactive Systems:** Pop-ups, chat interface, dynamic tables & micro-interactions  
- **📱 Responsive & Adaptive:** Perfectly optimized for desktop, tablet, and mobile
